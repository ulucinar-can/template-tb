\section{Protocole de mise en service}
\label{sec:Protocole}
La mise en service de la maquette s'effectue selon la procédure séquentielle suivante :
\begin{enumerate}
  \item Connecter le système à l'alimentation secteur.

  \item Patienter quelques secondes afin de permettre la charge complète du circuit de précharge.

  \item Actionner l'interrupteur principal d'alimentation.

  \item Activer la régulation de la maquette au moyen de l'interface web ou en pressant le bouton S2.
\end{enumerate}

\section{Calibration des capteurs de position}
\label{sec:CalibrationCaptPosManuel}
Les capteurs de position disposent d’une calibration appelée « Teach-in ». De plus amples détails sur cette méthode sont présentés dans la documentation technique du capteur \cite{CaptPosition}.

Les étapes pour réaliser une calibration selon la méthode « Teach-in » sont les suivantes :

\begin{enumerate}
  \item Presser la touche. La LED rouge s’allume lorsque l’apprentissage du détecteur est encore possible.

  \item Presser la touche pendant 5~secondes jusqu’à ce que la LED rouge commence à clignoter.

  \item Relâcher la touche.

  \item Placer l’objet de mesure à la limite de la plage de mesure pour laquelle le détecteur doit afficher une valeur de 0~V, respectivement de 4~mA.

  \item Presser brièvement la touche. La LED rouge s’allume pendant 3~secondes comme confirmation. Ensuite, elle se remet à clignoter de façon régulière.

  \item Placer l’objet de mesure à la limite de la plage de mesure pour laquelle le détecteur doit afficher une valeur de 10~V, respectivement de 20~mA. Presser brièvement la touche. La LED rouge s’allume pendant 3~secondes comme confirmation. Ensuite, elle s’éteint pour clignoter encore une fois brièvement. Le détecteur est alors de nouveau opérationnel.
\end{enumerate}

La seconde mesure, correspondant à la distance minimale, doit toutefois être réalisée suffisamment rapidement pour permettre au capteur d’enregistrer cette valeur.

Afin de faciliter la procédure de mesure, un programme dédié exclusivement à la régulation à courant constant a été développé. Ce fichier source est disponible dans le dossier \texttt{CourantConstant} (\red{A faire}).

L'exécution de ce code permet de plaquer les électroaimants contre les rails de guidage afin d'établir un entrefer nul (0~mm). La séquence d'étalonnage se déroule selon les étapes suivantes :

\begin{enumerate}
  \item L'activation de la régulation s'effectue par une impulsion sur le bouton-poussoir dédié, ce qui déclenche l'allumage d'une diode électroluminescente (LED) témoin.
  \item Les inducteurs doivent ensuite être relevés manuellement par leur base jusqu'au contact physique avec le rail. Il est impératif d'assurer le maintien simultané des quatre électroaimants contre la surface métallique afin d'éviter tout basculement angulaire susceptible de fausser la mesure.
  \item Une fois le contact parfaitement établi, la procédure d'apprentissage (\textit{teach-in}) de la position minimale peut être exécutée conformément aux instructions décrites précédemment.
  \item Après l'enregistrement de la butée haute (entrefer nul), une seconde impulsion sur le bouton désactive la régulation, provoquant la descente des électroaimants en butée basse. L'enregistrement de la position maximale du transducteur peut alors être finalisé.
\end{enumerate}

Une fois cette procédure terminée, le capteur est calibré.

\section{Mise en place de CCS}
\label{sec:MiseEnPlace}
\subsection{Installation de Code Composer Studio}
Afin de programmer correctement le DSP, une version spécifique de Code Composer Studio (CCS) ainsi qu'une bibliothèque dédiée au DSP doivent être installées.

La version requise de CCS est la suivante \cite{CCS_Install} :
\url{https://www.ti.com/tool/download/CCSTUDIO/12.6.0} \\

Pour la bibliothèque C2000Ware, la version suivante doit être installée \cite{C2000_Install} :
\url{https://www.ti.com/tool/download/C2000WARE/5.02.00.00}\\

\subsection{Configuration de CCS}

Une fois l'installation terminée, il est nécessaire de configurer CCS pour qu'il détecte la bibliothèque. La procédure d'intégration est la suivante :

\begin{enumerate}
  \item Lancer Code Composer Studio.

  \item Accéder au menu \textit{Window > Preferences}.

  \item Dans la colonne de gauche, naviguer vers \textit{Code Composer Studio > Products}.

  \item Vérifier la liste « Product discovery path ». Si le dossier \verb|C:\ti| n'y figure pas, cliquer sur \textit{Add...} et le sélectionner.
  \item Cliquer sur le bouton \textit{Refresh}.

  \item La bibliothèque C2000Ware doit apparaître dans la liste « Discovered products ». Cliquer alors sur \textit{Install}.

  \item Si l'explorateur de fichiers s'ouvre, sélectionner l'emplacement exact du dossier (généralement \verb|C:\ti\c2000\C2000Ware_5_02_00_00|).

  \item Vérifier que le dossier est correctement coché et cliquer sur \textit{Apply and close}. La \autoref{fig:Res_conf_C2000} illustre le résultat attendu.

        \begin{figure}[H]
          \centering
          \includegraphics[width=0.75\linewidth]{assets/appendix/01-Manuel/CCS/Resultat_conf_C2000.png}
          \caption{Résultat de la configuration du C2000}
          \label{fig:Res_conf_C2000}
        \end{figure}

  \item Une fois la configuration terminée, cliquer sur le bouton \textit{Build} pour appliquer les changements.
\end{enumerate}

Enfin, il est impératif de vérifier que le niveau d'optimisation de CCS est correctement établi en suivant ces étapes :

\begin{enumerate}
  \item Effectuer un clic droit sur le projet.

  \item Sélectionner \textit{Properties}.

  \item Dérouler l'onglet \textit{Build > C2000 Compiler > Optimization}.

  \item Appliquer les paramètres tels qu'illustrés dans la fenêtre suivante :

        \begin{figure}[H]
          \centering
          \includegraphics[width=0.75\linewidth]{assets/appendix/01-Manuel/CCS/CCS_Opti_Windows.png}
          \caption{Configuration des paramètres d'optimisation}
          \label{fig:Res_conf_Opti}
        \end{figure}
\end{enumerate}

Lorsque le programme final est prêt, celui-ci doit être écrit dans la mémoire flash afin de permettre un fonctionnement autonome (« stand-alone »).

Il est désormais possible d'utiliser CCS pour la programmation du DSP.

\section{Mesure des grandeurs de la régulation de position}
\label{annexe:MethodeMesurePosition}
Afin de réaliser une lecture et un enregistrement des données issues du programme principal, une fonction et un script Python ont été réalisés. Ceux-ci se trouvent dans le dossier \texttt{MesureSysteme} (\red{A faire}).

Il est nécessaire d'activer la liaison de communication via le câble USB (voir l'\autoref{annexe:LiaisonUSB}).

La fonction \texttt{SendFloatAsText} a été modifiée pour permettre un envoi plus important de valeurs. Celle-ci a été étendue à 32 valeurs afin de permettre l'envoi, pour chaque inducteur, de la consigne de position, de la position mesurée, de l'erreur de position, de la consigne de courant, du courant mesuré, de la consigne de force, de l'intégrale de la régulation de position et, pour finir, de la vitesse. La fonction résultante est la suivante :

\begin{minted}{c}
    void Send32FloatsAsCSV(float v[32])
    {
        char str[TX_BUF_LEN];
        int i = 0, j = 0, k = 0;

        // Ajoute les 31 premières valeurs suivies d'une virgule
        for(k = 0; k < 31; k++) {
            i += ftoa(v[k], &str[i], 4);
            str[i++] = ',';
        }

        // Ajoute la 32ème valeur sans virgule, suivie d'un retour à la ligne
        i += ftoa(v[31], &str[i], 4);
        str[i++] = '\n';

        // Copie dans le buffer UART
        for (j = 0; j < i && j < TX_BUF_LEN; j++) {
            txBuffer[j] = (uint8_t)str[j];
        }
        txLength = i;
        txIndex = 0;

        SCI_enableInterrupt(SCIA_BASE, SCI_INT_TXFF);
    }
\end{minted}

L'envoi se réalise comme suit :

\begin{minted}{c}
    /* --------------------------------------------------------------------- *
     * 3. COMMUNICATION (TELEMETRIE A 921600 BAUDS)
     * --------------------------------------------------------------------- */
    UartCounter++;
    if (UartCounter >= 250) // Envoi à 10 ms
    {
        UartCounter = 0;

        float telemetry[32];

        // --- Inducteur 1 ---
        telemetry[0] = Position_c1 * 1000.0f;
        telemetry[1] = Position1 * 1000.0f;
        telemetry[2] = ep1 * 1000.0f;
        telemetry[3] = ic1;
        telemetry[4] = Current1;
        telemetry[5] = fc1;
        telemetry[6] = xr1;
        telemetry[7] = v1;

        // --- Inducteur 2 ---
        telemetry[8] = Position_c2 * 1000.0f;
        telemetry[9] = Position2 * 1000.0f;
        telemetry[10] = ep2 * 1000.0f;
        telemetry[11] = ic2;
        telemetry[12] = Current2;
        telemetry[13] = fc2;
        telemetry[14] = xr2;
        telemetry[15] = v2;

        // --- Inducteur 3 ---
        telemetry[16] = Position_c3 * 1000.0f;
        telemetry[17] = Position3 * 1000.0f;
        telemetry[18] = ep3 * 1000.0f;
        telemetry[19] = ic3;
        telemetry[20] = Current3;
        telemetry[21] = fc3;
        telemetry[22] = xr3;
        telemetry[23] = v3;

        // --- Inducteur 4 ---
        telemetry[24] = Position_c4 * 1000.0f;
        telemetry[25] = Position4 * 1000.0f;
        telemetry[26] = ep4 * 1000.0f;
        telemetry[27] = ic4;
        telemetry[28] = Current4;
        telemetry[29] = fc4;
        telemetry[30] = xr4;
        telemetry[31] = v4;

        Send32FloatsAsCSV(telemetry);
    }
\end{minted}

Afin de garantir que la communication UART puisse transmettre cette quantité importante de données, le débit a été porté à 921600~bauds.

Pour réaliser la mesure, il est nécessaire de relier la carte d'évaluation à l'ordinateur. Une fois cela fait, il suffit de lancer le script Python, d'enclencher la maquette et de réaliser la mesure.

Une fois la mesure terminée, il suffit de suivre les indications du terminal pour la stopper. Il sera alors possible d'afficher la mesure par inducteur. Un fichier \texttt{.csv} sera également généré et pourra être employé dans un logiciel permettant de traiter les données.

\section{Protocole du mapping de la plaque}
\label{annexe:Mapping}
Pour réaliser un mapping de la plaque, un code de mesure et un script Python ont été réalisés. Ceux-ci se trouvent dans le dossier \texttt{Mapping} (\red{A faire}).

Le code emploie simplement la fonction déjà réalisée \texttt{SendFloatAsText} en envoyant les quatre valeurs de position filtrées.

Il est nécessaire d'activer la liaison de communication via le câble USB (voir l'\autoref{annexe:LiaisonUSB}).

Il suffit dès lors de compiler le code dans la carte d'évaluation et de lancer le script Python. Une fois cela fait, il ne reste qu'à suivre les indications du script.

Une fois la mesure terminée, un fichier \texttt{.csv} est sauvegardé.
