\chapter{Modification de la régulation}

\section{Introduction}
Ce chapitre vient traiter les modifications sur la régulation de courant ainsi que la nouvelle régulation de position. réaliser au cours de ce bachelor. La régulation de position en Single Input Single Output (SISO) n'ayant pas réussi a faire ses preuves, une régulation en Multiple Input Multiple Output (MIMO) fut envisagée et réalisé. Les détails de cette méthode sont décrite dans les sections a venir.

\section{Analyse de la régulation de courant}

\subsection{Erreur}

Une erreur majeure a cependant été identifiée dans les synthèses de régulation de courant antérieures. En effet, la constante $K_{ui}$ a été omise dans le système $G_{ui}$, comme le montre le code suivant :

\begin{minted}{matlab}
%% Inducteur Linéarisé autour de d_n = 2mm (avec terme en delta_d négliger p.12 journal)

Kui     = (d_n/i_n)^2*(m/L_n^2);
a1      = (d_n/i_n)^2*(m*R/L_n^2);
a2      = (d_n/i_n)^2*(m/L_n);

num     = [1 0];
den     = [a2 a1 1];
Gui     = tf(num,den); % Manque Kui
\end{minted}

Cette omission modifie significativement le comportement du système à régler. Les courbes montrent que le gain initial réel débute à environ -40~dB et non à 0~dB :
