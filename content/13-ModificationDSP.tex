\chapter{Modification apportée au programme principal (DSP)}

\section{Introduction}
À la suite des différentes modifications réalisées sur le hardware et sur la régulation, le programme principal a lui aussi reçu d'importantes modifications. Ce chapitre les présente.

L'ensemble du code est disponible sur la page GitHub créée pour ce projet.

La mise en place de Code Composer Studio est disponible dans le manuel, à la \autoref{sec:MiseEnPlace}.

\section{Machine d'état}
Une machine d'état a été réalisée. Elle enchaîne la régulation de courant puis la régulation de position, en respectant certaines étapes obligatoires pour réussir le décollage.

Une première version, uniquement SISO, est présentée dans l'\autoref{annexe:MachineEtatSISO}. Les étapes de la machine d'état finale sont les suivantes :

\begin{itemize}
    \item État 0 : attente de la pression du bouton.
    \item État 1 : montée du courant des inducteurs 1 et 2 à 3~A (pour ne pas partir de zéro).
    \item État 2 : augmentation du courant des inducteurs 1 et 2 par une rampe continue (régulation de courant seule).
    \item État 3 : dès que les inducteurs 1 et 2 commencent à bouger, passage en régulation de position SISO (lévitation de l'avant).
    \item État 4 : montée du courant des inducteurs 3 et 4 à 3~A.
    \item État 5 : augmentation du courant des inducteurs 3 et 4 par une rampe continue, puis bascule immédiate en régulation MIMO dès qu'un mouvement est détecté.
    \item État 6 : attente de l'arrêt de la maquette.
    \item État 7 : affichage d'un message d'erreur en cas de problème.
\end{itemize}

        }

    break;
\end{minted}

\begin{minted}{c}
    // State 1 :
    // Rampe de courant sur les inducteurs 1&2 jusqu'a atteindre les 3A
    case STATE_1:

        if(ic1 < I_SP)
        {
            ic1 += TAKEOFF_CURRENT_STEP1;
        }
        else
        {
            ic1 = I_SP;
        }

        ic2 = ic1;

        mean1 += Current1;

\end{minted}

L'état 2 est implémenté comme suit :

\begin{minted}{c}
    // State 2 :
    // Rampe de courant "infinie" jusqu'au decollage de l'avant
    case STATE_2:

        {
            uint16_t m;

            ic1 += TAKEOFF_CURRENT_STEP1;
        }
        else
        {

        }

        ic2 = ic1;

        break;
\end{minted}

L'état 3 est implémenté comme suit :

\begin{minted}{c}
    // State 3 :

    case STATE_3:

L'état 5 est implémenté comme suit :

\begin{minted}{c}
    // State 5 :
    // Rampe de courant "infinie" jusqu'au decollage de l'arriere,
    // puis bascule bumpless en regulation MIMO
    case STATE_5:

        if(Position3 <= Position_c3_dec && Position4 <= Position_c4_dec)
        {
            uint16_t j;
            float f_init0 = fc1f;
            float f_init1 = fc2f;
            float f_init2 = F_STAT[2];
            float f_init3 = F_STAT[3];

            for(j = 0; j < 3; j++)
            {
                float up = E_MAT[j][0]*f_init0 + E_MAT[j][1]*f_init1
                        + E_MAT[j][2]*f_init2 + E_MAT[j][3]*f_init3 - U_STAT[j];
                qm_ref[j] = qm[j];
                qm_est[j] = qm[j];
                vm_est[j] = 0.0f;
                um_est[j] = up;
                eps_m[j]  = -up * LQI_EPS_INV[j];
                u_cmd[j]  = up;
                u_sat[j]  = up;
                u_ach[j]  = up;
            }

            IN3[1] = F_STAT[2]; IN3[2] = F_STAT[2];
            OUT3[0] = F_STAT[2]; OUT3[1] = F_STAT[2];
            IN4[1] = F_STAT[3]; IN4[2] = F_STAT[3];
            OUT4[0] = F_STAT[3]; OUT4[1] = F_STAT[3];

            MimoFlag = true;

            state = STATE_6;
        }
        else if(ic3 < 9.5f)
        {
            ic3 += TAKEOFF_CURRENT_STEP1;
        }
        else
        {
            ic3 = 9.5f;
        }

        ic4 = ic3;


        break;
\end{minted}

Au moment de basculer en MIMO, l'observateur et les intégrateurs sont initialisés à partir des forces déjà appliquées par le SISO. Cette initialisation évite un saut de commande (transition \og bumpless \fg). La régulation MIMO démarre exactement sur l'état courant de la maquette, sans à-coup.

L'état 6 est implémenté comme suit :

\begin{minted}{c}
    // State 6 :
    // Attend que le bouton soit presse a nouveau pour eteindre la maquette
    case STATE_6:

        if(!SystemOn)
        {
            uint16_t j;

            for(i = 0; i < NUM_OF_PWM_CHANNEL; i++)

                HRPWM_setCounterCompareValue(ePWM[i], HRPWM_COUNTER_COMPARE_B, compCount);
            }

            PosRegFlag1 = false;
            MimoFlag = false;

            i_store = 0;

            integral_i1 = 0.0f; ue1 = 0.0f; ic1 = 0.0f;
            integral_i2 = 0.0f; ue2 = 0.0f; ic2 = 0.0f;
            integral_i3 = 0.0f; ue3 = 0.0f; ic3 = 0.0f;
            integral_i4 = 0.0f; ue4 = 0.0f; ic4 = 0.0f;

            xr1 = 0.0f; ep1 = 0.0f;
            xr2 = 0.0f; ep2 = 0.0f;

            for(j = 0; j < 3; j++)
            {
                eps_m[j] = 0.0f;
                u_cmd[j] = 0.0f;
                u_sat[j] = 0.0f;
                u_ach[j] = 0.0f;
                vm_est[j] = 0.0f;
                um_est[j] = 0.0f;
                qm_est[j] = qm[j];
                qm_ref[j] = qm_target[j];

            status = SFO();
            if (status == SFO_ERROR) error();

            state = STATE_0;
        }

        break;
\end{minted}

Il est possible d'arrêter la maquette à n'importe quel moment grâce à une simple condition placée en amont de la machine d'état :

\begin{minted}{c}
    if (!SystemOn && (state != STATE_0) && (state != STATE_6))
    {
        state = STATE_6;
    }
\end{minted}

La régulation s'active dès lors tant que l'état est différent de l'état 0 :

\begin{minted}{c}
    if(state != STATE_0)
    {
        ...
    }
\end{minted}

\section{Régulation de position}
La régulation de position a été largement modifiée. Une première partie reprend la synthèse SISO utilisée précédemment, tandis que l'implémentation de la méthode MIMO est nouvelle. Cette section présente ces implémentations.

La théorie de la synthèse MIMO (efforts modaux, retour d'état, observateur, allocation) est développée à la \autoref{sec:RegPosMIMO}. Cette section se limite à sa traduction en code. Les coefficients employés proviennent du script Python de synthèse, exporté directement dans le fichier \texttt{FunctionHeader.h}.

\subsection{Régulation SISO}
La régulation SISO reste identique à celle réalisée précédemment, issue de la synthèse de Yersin \cite{Yersin}. Elle ne sert qu'à lever l'avant de la maquette.

La vitesse est calculée comme auparavant, par dérivation de la position avec le filtre de Savitzky :

\begin{minted}{c}
    // AVANT (SISO) : estimation de la vitesse par derivateur Savitzky-Golay.
    if(PosRegFlag1 && !MimoFlag)
    {
        pos1Buff[FILTWINDOW-1] = Position1;
        v1 = savitzky_Filter(pos1Buff);

        pos2Buff[FILTWINDOW-1] = Position2;
        v2 = savitzky_Filter(pos2Buff);
    }
\end{minted}

La loi de régulation reste elle aussi identique à celle de Yersin \cite{Yersin}, avec les mêmes coefficients :

\begin{minted}{c}
    if(PosRegFlag1 && !MimoFlag)
    {
        // Loi de retour d'etat par inducteur :
        //   fc = Kw*consigne - Kd*position - Kddot*vitesse + Kr*integrale + m*g
        //   (Kw,Kd,Kddot,Kr < 0). Anti-windup par back-calculation (fce),
        //   puis coupe-bande IIR et transformee inverse force->courant.

        // --- Inducteur 1 ---
        // Calcul de la force de consigne 1
        ep1 = Position_c1 - Position1;
        xr1 += (ep1 - fce1);
        sum_vp1 = v1 * Kddot + Position1 * Kd;
        fc1_prim = Kw * Position_c1 + Kr * xr1 * I - sum_vp1 + FP;

        // Antiwindup
        fc1 = fc1_prim;
        if (fc1_prim <= 0)   fc1 = 0;
        if (fc1_prim >= FMAX1) fc1 = FMAX1;
        fce1 = (fc1_prim - fc1) * K_ANTIWINDUP * ANTIWINDUP_EN;

        // Filtre coupe bande
        IN1[0] = fc1;
        fc1f = IIR_Filter(IN1, OUT1);
        if (fc1f <= 0)   fc1f = 0;
        if (fc1f >= FMAX1) fc1f = FMAX1;

        // Calcul du courant de consigne 1
        ic1 = (sqrtf(K_FC1 * fc1f)) * Position1;

        // --- Inducteur 2 ---
        // Inductor 2 : Filtre Bandstop + State Regulation
        // Calcul de la force de consigne 2
        ep2 = Position_c2 - Position2;
        xr2 += (ep2 - fce2);
        sum_vp2 = v2 * Kddot + Position2 * Kd;
        fc2_prim = Kw * Position_c2 + Kr * xr2 * I - sum_vp2 + FP;

        // Antiwindup
        fc2 = fc2_prim;
        if (fc2_prim <= 0)   fc2 = 0;
        if (fc2_prim >= FMAX2) fc2 = FMAX2;
        fce2 = (fc2_prim - fc2) * K_ANTIWINDUP * ANTIWINDUP_EN;

        // Filtre coupe bande
        IN2[0] = fc2;
        fc2f = IIR_Filter(IN2, OUT2);
        if (fc2f <= 0)   fc2f = 0;
        if (fc2f >= FMAX2) fc2f = FMAX2;

        // Transform e inverse pour calculer le courant   partir de la force
        ic2 = (sqrtf(K_FC2 * fc2f)) * Position2;
    }
\end{minted}

Avec les coefficient provenant du travail de Yersin \cite{Yersin} :

\begin{minted}{c}
    // --- Retour d'etat SISO avant (inducteurs 1 & 2) ---
    // Loi : fc = KW*consigne - KD*position - KDDOT*vitesse + KR*integrale + m*g
    #define KW               ((float)-1.4862e4)   // gain sur la consigne de position
    #define KDDOT            -603.41f             // gain sur la vitesse (Savitzky)
    #define KD               ((float)-3.8998e4)   // gain sur la position mesuree
    #define KR               -35.63f              // gain de l'action integrale
\end{minted}

Cette partie ne sert qu'à lever l'avant, afin de faciliter le passage en régulation MIMO ensuite. Comme elle fonctionnait bien pour cet usage, elle a été conservée telle quelle.

\subsection{Implémentation des observateurs}
Un observateur est implémenté pour chaque mode (pompage, tangage, roulis). Il estime la position, la vitesse et l'effort à partir de la seule position mesurée, comme décrit au \autoref{subsec:observateur}. Il ne s'active qu'une fois la régulation MIMO enclenchée, donc uniquement lorsque le drapeau \texttt{MimoFlag} est vrai.

Chaque bloc de trois lignes traduit directement l'équation de mise à jour de l'observateur $\hat{x}[k+1] = A_d\,\hat{x}[k] + B_d\,u + L\,(y - C\hat{x})$. La variable \texttt{e\_obs} est l'écart entre la position mesurée \texttt{qm} et la position estimée \texttt{qm\_est}, corrigé par les gains \texttt{OBS\_L}. L'entrée injectée est \texttt{u\_ach}, l'effort réellement appliqué (recalculé après écrêtage et filtre coupe-bande), et non la commande brute, condition nécessaire à la validité de l'estimation :

\begin{minted}{c}
    // MIMO : observateur de Luenberger modal (position/vitesse/force par mode Z,T,R).
    if(MimoFlag)
    {
        float e_obs0 = qm[0] - qm_est[0];
        qm_est[0] = qm_est[0] + OBS_AD12[0] * vm_est[0] + OBS_L1[0] * e_obs0;
        float v_new0 = vm_est[0] + OBS_AD23[0] * um_est[0] + OBS_L2[0] * e_obs0;
        um_est[0] = OBS_AD33[0] * um_est[0] + OBS_BD3[0] * u_ach[0] + OBS_L3[0] * e_obs0;
        vm_est[0] = v_new0;

        float e_obs1 = qm[1] - qm_est[1];
        qm_est[1] = qm_est[1] + OBS_AD12[1] * vm_est[1] + OBS_L1[1] * e_obs1;
        float v_new1 = vm_est[1] + OBS_AD23[1] * um_est[1] + OBS_L2[1] * e_obs1;
        um_est[1] = OBS_AD33[1] * um_est[1] + OBS_BD3[1] * u_ach[1] + OBS_L3[1] * e_obs1;
        vm_est[1] = v_new1;

        float e_obs2 = qm[2] - qm_est[2];
        qm_est[2] = qm_est[2] + OBS_AD12[2] * vm_est[2] + OBS_L1[2] * e_obs2;
        float v_new2 = vm_est[2] + OBS_AD23[2] * um_est[2] + OBS_L2[2] * e_obs2;
        um_est[2] = OBS_AD33[2] * um_est[2] + OBS_BD3[2] * u_ach[2] + OBS_L3[2] * e_obs2;
        vm_est[2] = v_new2;
    }
\end{minted}

Les gains de l'observateur, exportés par le script de synthèse, sont définis dans \texttt{FunctionHeader.h} :

\begin{minted}{c}
    static const float OBS_AD12[3] = {4.00000000e-05f, 4.00000000e-05f, 4.00000000e-05f};
    static const float OBS_AD23[3] = {-2.53905745e-06f, -5.36684755e-05f, -5.36684755e-05f};
    static const float OBS_AD33[3] = {9.92837497e-01f, 9.92837497e-01f, 9.92837497e-01f};
    static const float OBS_BD3[3]  = {7.16250336e-03f, 7.16250336e-03f, 7.16250336e-03f};
    static const float OBS_L1[3]   = {8.26596051e-02f, 8.26596104e-02f, 8.26596104e-02f};
    static const float OBS_L2[3]   = {5.21497898e+01f, 5.21497966e+01f, 5.21497966e+01f};
    static const float OBS_L3[3]   = {-1.15564501e+05f, -5.46736182e+03f, -5.46736182e+03f};
\end{minted}


\subsection{Implémentation régulation MIMO}
La régulation MIMO s'active dès que l'arrière commence à se déplacer (état 5). Le bloc suivant reprend, dans l'ordre, les étapes de la synthèse développées à la \autoref{subsec:RetourEtat} et à la \autoref{subsec:RepartitionForces} :

\begin{enumerate}
    \item Lissage de la référence, puis calcul de la commande modale $u_{cmd}$ par la loi de retour d'état (gains \texttt{LQI\_Q}, \texttt{LQI\_QD}, \texttt{LQI\_EPS}), pour les trois modes.
    \item Allocation des trois efforts vers les quatre forces via la matrice \texttt{W\_MAT}, avec ajout de la compensation de poids \texttt{F\_STAT}.
    \item Limitation de chaque force entre $0$ et $F_{max}$.
    \item Anti-windup : les efforts réellement réalisés sont recalculés avec \texttt{E\_MAT} à partir des forces saturées, et chaque intégrateur \texttt{eps\_m} n'est incrémenté que si son mode n'est pas saturé (tolérance \texttt{AW\_TOL}).
    \item Filtre coupe-bande, puis conversion force $\to$ courant par la méthode inverse.
    \item Calcul de l'effort réellement appliqué \texttt{u\_ach}, réinjecté dans l'observateur.
\end{enumerate}

L'implémentation est la suivante :

\begin{minted}{c}
    if(MimoFlag)
    {
        qm_ref[0] += (qm_target[0] - qm_ref[0]) * REF_SMOOTH;
        u_cmd[0] = LQI_Q[0]*(qm[0] - qm_ref[0]) + LQI_QD[0]*vm_est[0] - LQI_EPS[0]*eps_m[0]*I;
        qm_ref[1] += (qm_target[1] - qm_ref[1]) * REF_SMOOTH;
        u_cmd[1] = LQI_Q[1]*(qm[1] - qm_ref[1]) + LQI_QD[1]*vm_est[1] - LQI_EPS[1]*eps_m[1]*I;
        qm_ref[2] += (qm_target[2] - qm_ref[2]) * REF_SMOOTH;
        u_cmd[2] = LQI_Q[2]*(qm[2] - qm_ref[2]) + LQI_QD[2]*vm_est[2] - LQI_EPS[2]*eps_m[2]*I;

        fc1 = F_STAT[0] + W_MAT[0][0]*u_cmd[0] + W_MAT[0][1]*u_cmd[1] + W_MAT[0][2]*u_cmd[2];
        fc2 = F_STAT[1] + W_MAT[1][0]*u_cmd[0] + W_MAT[1][1]*u_cmd[1] + W_MAT[1][2]*u_cmd[2];
        fc3 = F_STAT[2] + W_MAT[2][0]*u_cmd[0] + W_MAT[2][1]*u_cmd[1] + W_MAT[2][2]*u_cmd[2];
        fc4 = F_STAT[3] + W_MAT[3][0]*u_cmd[0] + W_MAT[3][1]*u_cmd[1] + W_MAT[3][2]*u_cmd[2];

        if (fc1 < 0) fc1 = 0; else if (fc1 > FMAX1) fc1 = FMAX1;
        if (fc2 < 0) fc2 = 0; else if (fc2 > FMAX2) fc2 = FMAX2;
        if (fc3 < 0) fc3 = 0; else if (fc3 > FMAX3) fc3 = FMAX3;
        if (fc4 < 0) fc4 = 0; else if (fc4 > FMAX4) fc4 = FMAX4;

        u_sat[0] = E_MAT[0][0]*fc1 + E_MAT[0][1]*fc2 + E_MAT[0][2]*fc3 + E_MAT[0][3]*fc4 - U_STAT[0];
        float def0 = u_cmd[0] - u_sat[0];
        if (def0 > -AW_TOL[0] && def0 < AW_TOL[0]) eps_m[0] += (qm_ref[0] - qm[0]) * H;

        u_sat[1] = E_MAT[1][0]*fc1 + E_MAT[1][1]*fc2 + E_MAT[1][2]*fc3 + E_MAT[1][3]*fc4 - U_STAT[1];
        float def1 = u_cmd[1] - u_sat[1];
        if (def1 > -AW_TOL[1] && def1 < AW_TOL[1]) eps_m[1] += (qm_ref[1] - qm[1]) * H;

        u_sat[2] = E_MAT[2][0]*fc1 + E_MAT[2][1]*fc2 + E_MAT[2][2]*fc3 + E_MAT[2][3]*fc4 - U_STAT[2];
        float def2 = u_cmd[2] - u_sat[2];
        if (def2 > -AW_TOL[2] && def2 < AW_TOL[2]) eps_m[2] += (qm_ref[2] - qm[2]) * H;

        IN1[0] = fc1;
        fc1f = IIR_Filter(IN1, OUT1);
        if (fc1f < 0) fc1f = 0; else if (fc1f > FMAX1) fc1f = FMAX1;
        ic1 = sqrtf(K_FC1 * fc1f) * Position1;

        IN2[0] = fc2;
        fc2f = IIR_Filter(IN2, OUT2);
        if (fc2f < 0) fc2f = 0; else if (fc2f > FMAX2) fc2f = FMAX2;
        ic2 = sqrtf(K_FC2 * fc2f) * Position2;

        IN3[0] = fc3;
        fc3f = IIR_Filter(IN3, OUT3);
        if (fc3f < 0) fc3f = 0; else if (fc3f > FMAX3) fc3f = FMAX3;
        ic3 = sqrtf(K_FC3 * fc3f) * Position3;

        IN4[0] = fc4;
        fc4f = IIR_Filter(IN4, OUT4);
        if (fc4f < 0) fc4f = 0; else if (fc4f > FMAX4) fc4f = FMAX4;
        ic4 = sqrtf(K_FC4 * fc4f) * Position4;

        u_ach[0] = E_MAT[0][0]*fc1f + E_MAT[0][1]*fc2f + E_MAT[0][2]*fc3f + E_MAT[0][3]*fc4f - U_STAT[0];
        u_ach[1] = E_MAT[1][0]*fc1f + E_MAT[1][1]*fc2f + E_MAT[1][2]*fc3f + E_MAT[1][3]*fc4f - U_STAT[1];
        u_ach[2] = E_MAT[2][0]*fc1f + E_MAT[2][1]*fc2f + E_MAT[2][2]*fc3f + E_MAT[2][3]*fc4f - U_STAT[2];
    }
\end{minted}

\section{Mise en place du code dans la flash}
Le code a jusqu'ici été exécuté depuis la RAM. Il fonctionne correctement et donne le résultat attendu.

Cependant, une fois le code placé dans la flash, l'interruption ne s'exécutait plus assez rapidement, ce qui provoquait de très fortes oscillations. Il a donc été décidé de conserver certaines parties du code en RAM plutôt qu'en flash. L'interruption principale, par exemple, est allouée en RAM comme suit :

\begin{minted}{c}
    #ifndef RAM
    #pragma CODE_SECTION(adcA1ISR, ".TI.ramfunc")
    #endif
    __interrupt void adcA1ISR(void)
    {
        ...
    }
\end{minted}

Cette allocation ne s'applique que lorsque le code est compilé pour la flash. Lorsqu'il est exécuté depuis la RAM, la condition la saute.

Les parties allouées à la RAM sont les suivantes :

\begin{itemize}
    \item L'interruption principale
    \item Les deux interruptions liées à la communication UART
    \item La fonction de régulation de courant
    \item La fonction du filtre Savitzky
    \item La fonction du coupe-bande
    \item La fonction dédiée à l'envoi des données à l'ESP32
\end{itemize}

Le résultat se rapproche de celui obtenu en RAM, mais reste moins satisfaisant, la maquette oscillant davantage.

\section{Modifications mineures}
Différentes modifications furents appliquer aux codes. Ceux-ci n'ayant pas un impacte majeure mais concernant plus un aspect structurelle au code sont décrit dans cette section.

\subsection{Amélioration du code via l'IA}
Afin d'optimiser l'appropriation du code source hérité, une première révision syntaxique a été réalisée à l'aide d'outils d'intelligence artificielle. Cette démarche avait pour objectif d'améliorer la structure du programme, d'enrichir les commentaires et d'en accroître la lisibilité globale. Le comportement de la maquette a été rigoureusement contrôlé à la suite de cette restructuration purement formelle. Les résultats obtenus étant strictement identiques à ceux de la version d'origine, il est confirmé que cette intervention n'a introduit aucun dysfonctionnement supplémentaire.

\subsection{Création d'un fichier secondaire .c}
Ce fichier constitue une révision du travail initial de Thomas Freyche. Afin d'améliorer la clarté et la modularité du code, les définitions ont été réparties sur deux fichiers distincts, la logique restant strictement identique. Ce second fichier regroupe les nombreuses fonctions du programme.

\subsection{Modification des coefficients du filtre coupe-bande}
Toutefois, lors de l'analyse du code source hérité, il a été constaté que ces définitions n'étaient pas utilisées. Une autre variante de coefficients était active :

\begin{minted}{c}
//bandstop Filter 56Hz 2nd order bande coupe de 47Hz  90Hz (0) (test)
#define A1_B1_0         -1.980143772501098
#define A2_0            0.980339665209542
#define B0_B2_0         0.9901698326047711
\end{minted}

Cette disparité provient vraisemblablement d'essais expérimentaux antérieurs non documentés. Par souci de cohérence avec le travail de Laucella \cite{Laucella}, les paramètres ciblant la fréquence de 75~Hz ont été restaurés.

Par ailleurs, une mesure a été réalisée sans le filtre afin d'observer son comportement. Elle est disponible dans l'annexe \red{A faire}.

\subsection{Modification de l'emplacement du filtre coupe-bande}
Afin d'éviter un retard d'une période de 40~$\mu$s, le filtre a été placé juste après le calcul de la force. Précédemment, celui-ci se trouvait avant ce calcul et était employé pour le calcul de la consigne de courant.

\subsection{Modification de la variable d'enclenchement}
Le système utilisait deux variables distinctes pour l'enclenchement et le déclenchement de la maquette. Si la maquette était enclenchée par le bouton mais coupée depuis l'interface web, la commande n'avait aucun effet. Une seule variable a donc été retenue pour gérer à la fois l'enclenchement et le déclenchement.

\section{Conclusion}
Les différentes implémentations réalisées ont permis d'obtenir un code bien plus structuré que les versions précédentes.

Le programme a été testé et son bon fonctionnement a été confirmé.

Il reste maintenant à améliorer la régulation de position. La structure est en place ; il faut désormais y implémenter les bons coefficients.
